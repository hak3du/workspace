3. API routes (all `export const dynamic = "force-dynamic"`, try/catch → `NextResponse.json({error},{status})`, `getSessionUser()`, `db` from `@/lib/db`, Next 16 `params: Promise<{ id: string }>`):
   - `GET /api/posts` — `tab` foryou|following|video|image|audio|article|live (default foryou), `spaceId?`, `q?` (contains on title/body), `limit` (1..50, default 24). video/image/audio/article → exact post type; live → `isLive:true`; **following = documented approximation**: authors sharing a SpaceMembership with the session user + seeded @dylanhodges/@miraquant. Order `isLive desc, createdAt desc`. Includes author + `space{id,name,slug}`; LIKE/SAVE flags resolved via one Reaction query (`postId in ids`, `kind in [LIKE,SAVE]`). Returns `{ posts: PostDTO[] }` built with bootstrap's `toPost(p, {liked, saved})`.
   - `POST /api/posts` — validates type ∈ {VIDEO,IMAGE,ARTICLE,AUDIO,UPDATE,CODE}, title 3–120, body ≤2000, tags trimmed/lowercased max 5 (JSON-stringified), `spaceId` verified to exist, `durationLabel` trimmed ≤16; creates with session author. **No ActivityEvent for posts (per spec).** Returns `{ post }` 201.
   - `GET /api/posts/[id]` — post with liked/saved + latest 50 comments (fetched desc, reversed to asc) with authors. 404 on missing. Returns `{ post, comments: CommentDTO[] }`.
   - `POST /api/posts/[id]/like` and `/save` — toggle Reaction (unique `postId_userId_kind`); count updated to explicit clamped value (`Math.max(0, n±1)`) instead of raw decrement so counts can't go negative. Returns `{ liked|saved, likeCount|saveCount }`.
   - `POST /api/posts/[id]/comments` — body 1–500; `$transaction` [post.commentCount+1, comment.create with author]. Returns `{ comment, commentCount }` 201.
   - `GET /api/spaces` — memberCount desc, owner + `_count.posts` as `postCount`, `joined` from one membership query. Exports a shared `toSpace()` converter (used by `[id]` route too). Returns `{ spaces: SpaceDTO[] }`.
   - `POST /api/spaces` — name 3–40, tagline ≤120, category ∈ {GAMING,MUSIC,AI,CYBERSEC,ART,STARTUP,EDU,ARENA}, iconEmoji default 🚀, gradient default `from-violet-600 to-cyan-500`, visibility PUBLIC|PRIVATE; slugified name with collision-safe suffix loop; creates space + OWNER membership atomically (nested create), memberCount 1. Returns `{ space }` 201.
   - `GET /api/spaces/[id]` — resolves by id **or slug**; returns `{ space: SpaceDTO & {joined, myRole}, posts (latest 12, flags), members: (UserDTO & {role})[] (latest 12), events (asc), messages (latest 40 asc) }`. `myRole` null when not a member.
   - `POST /api/spaces/[id]/join` — toggle membership; owner cannot leave (400); memberCount clamped ≥0; JOIN ActivityEvent `"{user} joined {space}"` emitted **on join only**. Returns `{ joined, memberCount }`.
   - `GET /api/spaces/[id]/messages?after=ISO` — asc, `createdAt > after` for 4s polling; `POST` — body 1–400, **membership not required**. Returns `{ messages }` / `{ message }` 201.
